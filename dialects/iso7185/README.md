# ISO 7185 Standard Pascal

Minimal standardized Pascal baseline.

Scope:

- program structure
- constants
- types
- variables
- arrays
- records
- sets
- enumerations
- subranges
- pointers
- procedures
- functions
- control flow
- case statements
- files
- standard operators
- lexical rules

No Delphi-specific syntax is permitted in ISO 7185 conformance tests.
